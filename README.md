# Chess Clock

FIDE標準の持ち時間に対応した、iPhone向けのチェスクロック。
外部依存ゼロの単一HTML + Service Worker で、**オフラインでも動作**します。

## 時間設定

並びは chess.com の対局作成画面に合わせてあります。既定は **15 | 10**（FIDE公式ラピッド）。

chess.com 自体の既定は 10分（加算なし）ですが、物理クロックは指してからボタンを押すまでの
時間も持ち時間から引かれるため、加算のある 15 | 10 を既定にしています。

| 区分 | プリセット |
|---|---|
| バレット | 1分 ／ 1 \| 1 ／ 2 \| 1 |
| ブリッツ | 3分 ／ 3 \| 2 ／ 5分 |
| ラピッド | 10分 ／ 15 \| 10 ／ 30分 |
| クラシカル | 90\|30・40手（FIDE標準） ／ 120\|30・40手 ／ 90 \| 30 |
| その他 | カスタム（持ち時間・加算・区切り手数・追加時間を自由設定） |

40手を指した瞬間に次の期間の時間が自動で加算され、「第◯期間まであと◯手」を常時表示します。

## 特徴

- **実機同等のデジタル表示** — 表示はすべて7セグメント。1枚の黒い液晶パネルに
  2つのタイマーが左右に並びます。外部フォントを使わずSVGで直接描画しているので、
  どのサイズでも輪郭が潰れず、オフラインでも表示できます

  ```
   1:30  000        30         59:47  012
         00          ◀                  .3
   └時:分┘└手数┘  └加算秒┘
              └秒┘        └手番の向き┘
  ```

- **天板のロッカー** — 実機と同じ白いシーソーを再現。**浮いている側がいま動いている側**で、
  押されて沈んだ側はフラットのまま、動いている側が下端を揃えたまま外側へ向かって
  厚みを増す楔形に持ち上がります。手番の切り替えを受け付けるのはこのロッカーだけで、
  液晶は表示専用です
- **手番表示** — 中央の三角が動作中の側を指し、その側だけ明るく点灯、
  コロンが1秒周期で点滅します。三角は対局が始まってから現れます
- **残り時間の警告** — 残り1分を切るとその側のセグメントが赤くなり、
  秒の欄が0.1秒単位に切り替わります。時間切れは赤く点滅します
- **休憩ポーズ** — ▶/⏸ のトグルで両者の時計を停止。休憩中と経過時間は液晶下に表示され、
  累計も記録します（※FIDE公式ルールでは対局中に時計を止めることはできません。カジュアル用）
- **スリープ防止** — Wake Lock API で対局中は画面が消えません
- **日本語 / English** — 設定から切り替え。既定は日本語で、選択は次回も維持されます
- **設定の保存** — 選んだ持ち時間は次回も維持されます

## 使い方

**浮いている側が、いま時計が動いている側です**（実物のチェスクロックと同じ）。

- **対局前** — 天板を押して後手側を沈める＝先手側が浮く（既定は左が先手）。何度でも切り替え可
- **開始** — 中央の ▶ を押すと、浮いている側の時計が動き出します
- **以降** — 自分の手を指したら自分側のボタンを押す。自分が沈んで止まり、相手が浮いて動き出します
- **休憩** — 動作中は中央が ⏸ になり、押すと両者停止。もう一度 ▶ で再開（画面は覆いません）
- 手番でない側を押しても何も起きません（誤操作防止）
- 液晶に触れても手番は動きません（盤を覗き込むときの誤操作を防ぐため）

先手がどちらの席かはアプリ側で持たず、対局前に沈めた側がそのまま先手になります。
白が右に座っていてもそのまま使えます。

## iPhoneにインストール

1. Safari でこのページを開く
2. 共有ボタン <kbd>􀈂</kbd> → **ホーム画面に追加**
3. ホーム画面のアイコンから起動すると、全画面アプリとして動作します

## 開発

単一ファイル構成です。`index.html` を直接編集してください。

- `index.html` — アプリ本体（HTML + CSS + JS、すべてインライン）
- `sw.js` — オフラインキャッシュ
- `manifest.webmanifest` — PWAマニフェスト
- `make-icon.py` — アイコン生成（`python3 make-icon.py`）
